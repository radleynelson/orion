Config options for custom agents

A practical system could support explicit icons but still produce good defaults when config is missing.

Simple config surface

Use provider as the base identity for Claude/Codex, then let optional agent fields choose from a small role icon set for custom agents.

  • provider = "claude" or provider = "codex" can map to official provider art if we decide to bundle it.
  • icon = "review", "test", "deploy", "data", etc. maps to the fixed picker above.
  • color = "amber" or a hex value controls custom roles.
  • If no icon exists, use initials plus a deterministic hash color.

My read

Based on your notes: A is the activity rail direction. For the project mark, O7 is the strongest new pass because it reads as Orion, not just generic connected nodes. For agents, the brand-icon route is possible, but I would only do it with bundled/approved SVG assets; custom agents should use the limited role picker so the system stays controlled.
